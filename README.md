# Guardian AI - Smart Home Security Assistant

Vite + React + Supabase app for a college AI essentials project.

## Required Environment Variables

Frontend:

- `VITE_SUPABASE_PROJECT_ID`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_URL`

Supabase Edge Function secrets:

- `GEMINI_API_KEY`
- `OPENWEATHER_API_KEY`
- `NEWS_API_KEY`
- `TELEGRAM_BOT_TOKEN`
- `SUPABASE_SERVICE_ROLE_KEY`

## Local Commands

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
```
